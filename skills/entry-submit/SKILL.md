# /ai-challenge-kit:entry-submit 応募フォームに入力する

`<スキルのフォルダ>` は、この `SKILL.md` が置かれているフォルダの絶対パス（パソコン内での完全な場所）のことです。スクリプトは作業フォルダ（`challenge/` があるフォルダ）で実行し、`<スキルのフォルダ>` はスキルを読み込んだときに分かる実際のパスに置き換え、空白があっても動くよう引用符で囲みます。

**どちらの方法でも、同意3点のチェックには触れません。送信ボタンは押さない決まりです。**

## 手順

1. ワークスペース直下の `challenge/entry_form.json`（応募内容をまとめたファイル）を読みます。無ければ /ai-challenge-kit:entry-form を案内して止まります。
2. 氏名、連絡用メール、アイデアのタイトル、アイデア概要、応募カテゴリー、動画 URL に空欄がないか確かめます。氏名やメールが空なら、本人に聞きます。ほかの必須項目も、質問は一度に1つにして、答えを待ちます。確認した内容を `challenge/entry_form.json` に反映してから進みます。
3. YouTube の動画 URL が入り、YouTube Studio の公開設定が「限定公開」になっていることを本人に確かめてもらいます。
4. 次の2つから本人に選んでもらいます。迷ったら②を勧めます。
   1. **Antigravity のブラウザ操作**が使える場合は、公式の応募フォームを開き、ページの「応募者情報」「作品情報」「作品の PR」の入力欄に下書きを入れます（公式フォームはタブではなく、1ページに縦に並んでいます）。同意3点のチェックには触れず、送信ボタンは押さないでください。入力欄を確かめられなければ、本人に手で貼り付けてもらいます。[公式の応募フォーム](https://googlejp25.withgoogle.com/awards-form)
   2. **Playwright**（ブラウザに入力するための道具）を使うスクリプトで入力します。入力中のブラウザの画面が本人の PC に表示されます。
   - **Google Cloud Shell の場合**（環境変数 `CLOUD_SHELL` が `true`）は、①も②も使いません。Cloud Shell のブラウザは画面のない形でしか動かず、入力した画面を本人が見て送信できないためです。[入力欄が見つからないとき](references/field_notes.md) の項目一覧の順に、`challenge/entry_form.json` の文章を項目ごとにコピーしやすく表示し、本人が自分の PC のブラウザで公式の応募フォームを開いて貼り付けるよう案内して、手順6へ進みます。
5. ②を選んだときは、初回だけ、本人の PC でワークスペース直下を開いたターミナル（コマンドを入力する画面）で次を実行するよう案内します。

   ```text
   cd <スキルのフォルダ>/scripts && npm install && npx playwright install chromium
   ```

   `&&` が使えない場合は、区切りごとに1行ずつ実行します。準備ができたら、ワークスペース直下に戻って次を実行します。

   ```text
   node <スキルのフォルダ>/scripts/fill_form.mjs
   ```

   入力欄が見つからなければ、項目一覧と手で貼り付ける手順を案内します。[入力欄が見つからないとき](references/field_notes.md)
6. 入力した画面を本人に見せて、次のように伝えます。「同意3点のチェックと送信ボタンは押していません。同意事項を読んでチェックし、内容を確かめて、自分で送信ボタンを押してください。締切後は直せません。」締切は **2026/11/30 23:59** です。締切後は再提出もできません。②では、ターミナルで Enter を押すとブラウザが閉じるので、確認と送信が終わるまでターミナルはそのままにします。
7. 送信後は、受付の自動返信メールが届いたか確かめるよう案内します。届かないときは、迷惑メールフォルダと応募時のアドレスの打ち間違いを確かめ、公式 FAQ を見てもらいます。[公式 FAQ](https://googlejp25.withgoogle.com/faq)
8. `challenge/progress.md` があれば、手で貼り付けた分を含めて入力が終わった時点で「フォームに入力」を「済」にし、「送信は本人が行う」と記録します。この段がなければ既存の表に追加します。ファイルがなければ、新しく作らず /ai-challenge-kit:challenge を勧めます。案内と記録が済んだら、ブラウザの操作は本人に渡して止まります。

## 気をつけること

- ログインやパスワードの入力、課金の確定は本人が行います。API キーやパスワードはファイルに書きません。
