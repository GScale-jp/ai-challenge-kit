# コザから考える14のシナリオ

KOZAROCKS 2026 のテーマ「文創開化」は、AI でたくさんのものを作れる時代に、土地の歴史や人の物語など、再現できないものを「活かして創る」という考え方です。キーワードはスタートアップ（新しい事業への挑戦）、万国津梁（国や地域をつなぐ架け橋）、音楽・ロックです。商店街、エイサー、模合（互いに助け合う集まり）、台湾との結びつきも題材にしました。架空の例を、自分が知っている場面に置き換えて考えます。

試作に使える道具は、Gemini（文章や画像などを扱う AI）、Google AI Studio（Gemini を試せる画面）、Antigravity（AI と一緒にアプリを作る道具）、Apps Script（GAS。Google 上で動く小さなプログラム）、Google Cloud の Cloud Run（サーバーでアプリを動かすサービス）です。

出典は [KOZAROCKS 2026](https://kozarocks2026.koza.rocks/) と [Google AI Challenge](https://googlejp25.withgoogle.com/awards/) です。

## シナリオ 1: ライブの空き日に出番をつくる
- 誰が: 商店街の小さなライブハウスの運営役と、初出演を目指すバンドです。
- どんな場面: 急に空いた平日の枠に、演奏できる人を探すときです。
- 困りごと: 募集文と自己紹介の書き方がばらばらで、条件を照らし合わせるのに時間がかかります。
- AI で何が変わる: Gemini が演奏時間や機材条件を文章から抜き出し、合いそうな枠とその理由を並べます。
- 部門: はたらく・まなぶ
- 作るなら最小の形: GAS Web アプリで、架空の募集枠3件と出演希望3件を表に置いて照合します。
- 審査基準でのひとこと: 独創性は会場ごとの演奏条件を生かせる点が強く、貢献度は調整時間の比較が必要です。

## シナリオ 2: 昔話を聴きながら商店街を歩く
- 誰が: 商店街の成り立ちを伝えたい案内役と、初めて訪れる人です。
- どんな場面: 建物の前で、そこでどんな出来事があったかを知りたいときです。
- 困りごと: 案内板だけでは話し手の記憶や言い回しが残りにくく、外国語向けの案内も作りにくいです。
- AI で何が変わる: Google AI Studio で Gemini に架空の昔話の音声を渡し、元の話に戻って確認できる短い日本語と中国語の案内文を作ります。
- 部門: まちと地球の未来
- 作るなら最小の形: 静的 Web アプリで、架空の地点2か所の音声と案内文を並べます。
- 審査基準でのひとこと: 独創性は声と土地の記憶が結びつく点が強く、AI 活用の有効性は固有の言い回しを訳せるかの確認が必要です。

## シナリオ 3: 模合の集まりを家族で確認する
- 誰が: 模合に参加する家族と、その集まりの予定を把握したい家族です。

- 困りごと: メモが散らばり、すでに返事をしたか思い出せません。
- AI で何が変わる: Gemini が架空の連絡文から日程や返事の期限を抜き出し、書かれていない箇所を確認項目として示します。
- 部門: 暮らしと家族
- 作るなら最小の形: GAS Web アプリで、架空の出欠と積立の予定を表で確認します。
- 審査基準でのひとこと: 貢献度は家族の確認の手間を減らせる点が強く、独創性は一般的な予定表との差を示す必要があります。

## シナリオ 4: エイサーの隊列を振り返る
- 誰が: エイサーの隊列に初めて加わる練習参加者です。
- どんな場面: 練習後に、どこで列の間隔が変わったか振り返るときです。
- 困りごと: 長い動画の中で確認すべき場面を探すのに時間がかかります。
- AI で何が変わる: Gemini に紙の人形で再現した短い映像を渡し、隊列の間隔が開いたように見える時刻と、見直す観点を出します。
- 部門: はたらく・まなぶ
- 作るなら最小の形: Cloud Run で、短い映像の確認箇所を返す画面を1つ作ります。
- 審査基準でのひとこと: AI 活用の有効性は見直す場面を絞れる点が強く、展開可能性は隊列や撮り方が違う場合の検証が必要です。

## シナリオ 5: 台風の前に家族で備えを分ける
- 誰が: コザに住み、誰がどこまで備えを済ませたか分からずに困る家族です。
- どんな場面: 台風が近づく前に、飲み水や懐中電灯などを家で確認するときです。
- 困りごと: 口頭だけで分担すると、同じ物を用意したり、誰も確認していない物が残ったりします。
- AI で何が変わる: Gemini が架空の家族の人数や住まいに合わせてリストの案を作り、家族が確認して分担します。
- 部門: 暮らしと家族
- 作るなら最小の形: 静的 Web アプリで、確認済みの項目と担当を同じ端末に保存します。Gemini には別画面で案を作ってもらいます。
- 審査基準でのひとこと: 貢献度は準備の抜けに気づける点が強く、AI 活用の有効性は固定のリストでは足りない場面を示す必要があります。

## シナリオ 6: 台湾からの旅行者と店で会話する
- 誰が: 台湾から来た旅行者と、商店街で働く人です。

- 困りごと: 単語だけの翻訳では、相手がどの食材や食べ方について尋ねているか伝わりにくいです。
- AI で何が変わる: Gemini が架空のメニューをもとに質問を言い換え、日本語と繁体字の中国語で確認文を1つずつ示します。
- 部門: はたらく・まなぶ
- 作るなら最小の形: Cloud Run で、架空のメニュー3品を使い、一問一答ができる画面を作ります。
- 審査基準でのひとこと: 貢献度は聞き返しを減らせる点が強く、独創性は一般の翻訳との違いが分かる会話例が必要です。

## シナリオ 7: 家族で聴くコザの音楽の話

- どんな場面: 家で昔の音楽の話を聞き、子どもが続きを尋ねるときです。
- 困りごと: 当時の会場や音楽の用語が分からず、聞きたいことを思いつきません。
- AI で何が変わる: Gemini が架空の語りの中から子どもにも分かる聞き返しを作り、会話のきっかけを増やします。
- 部門: 暮らしと家族
- 作るなら最小の形: 静的 Web アプリで、Antigravity を使って語りと質問カードを切り替える画面を作ります。
- 審査基準でのひとこと: 独創性は土地の音楽の記憶を会話の入口にする点が強く、展開可能性は別の家族でも質問を選びやすいかの確認が必要です。

## シナリオ 8: 商店街の記憶地図をつくる

## シナリオ 10: ライブ後の分別案内をつくる
