# /ai-challenge-kit:entry-form 応募フォームの下書き

公式のフォーム（https://googlejp25.withgoogle.com/awards-form）の項目は、2026/11/19 に確かめた時点で次のとおりです。詳しい一覧は、/ai-challenge-kit:entry-submit のスキルに入っている資料 `field_notes.md` にあります。

- 必須: 名前（フルネーム）、連絡先メールアドレス、アイデアのタイトル、アイデアの概要（100 文字以内推奨）、応募カテゴリー（3部門から1つ）、デモ動画の URL
- 任意: ペンネーム、主に使用した AI ツール（複数選択可）、成果物・制作物の URL
- 作品の PR の3欄（各 400 文字以内推奨）: 背景（Insight & Purpose）、AI の使い方・工夫（Creativity & How）、生まれた変化・広がり（Impact & Scalability）。見出しは「任意」ですが、入力欄には必須の指定が付いているので、3つとも書きます。

## 手順

1. `challenge/requirements.md` を読む（無ければ /ai-challenge-kit:kabeuchi を案内して止まる）。`challenge/idea.md`、`challenge/video_script.md`、`challenge/deploy.md` があれば、内容が食い違わないように読む。
2. **氏名とメールアドレスを本人に聞く。** 質問は一度に1つ。氏名は本名で、チームで応募する場合は代表者の名前（応募は個人かグループ、代表1名）。メールは審査結果や連絡が届く、本人がいつも見ているアドレス。ペンネーム（受賞発表で別の名前を使いたい場合だけ）も聞く。答えたくない場合は空にして、あとで本人が入力する。聞いた内容は、チャットの返答以外に残さず、`challenge/entry_form.md` と `challenge/entry_form.json` に書く（個人情報なので、Git にコミットしない・他人に共有しない）。
3. `challenge/entry_form.md` に次の見出しで書く。
   - `# 応募フォームの下書き`
   - `## 氏名`、`## メールアドレス`、`## ペンネーム`
   - `## タイトル案`: 番号つきで3つ
   - `## アイデアの概要`
   - `## 部門`
   - `## 使った AI ツール`
   - `## 動画のURL`: 「（YouTube に限定公開でアップしたあと、本人が貼る）」と書く
   - `## 作品の PR（背景）`、`## 作品の PR（AI の使い方・工夫）`、`## 作品の PR（生まれた変化・広がり）`
   - `## 成果物のURL`: /ai-challenge-kit:deploy で得た URL があれば書く。無ければ「（なし）」
   - `## 自分の言葉で書き足す一か所`
   - `## 審査基準の確認`
4. **タイトル案は3つ**。何のアプリかが一目で分かる言葉で、短く（20字前後）。1つ目は直球、2つ目は場面が浮かぶもの、3つ目は少し印象に残るもの。本人に1つ選んでもらう。
5. **アイデアの概要**は、フォームの案内に合わせて100字以内を目安に、読みやすい長さで書く（字数は目安で、超えても受け付けは止まらないが、短いほうが伝わる）。誰の・どんな困りごとを、Google の AI でどう変えるかが、1〜3文で分かるようにする。
6. **作品の PR の3欄**は、それぞれ400字以内を目安に、審査基準4つ（独創性・社会や暮らしへの貢献度・AI活用の有効性・展開可能性）が読み手に伝わるように書く。
   - 背景: どんな課題を解決するか、きっかけは何か（貢献度）。具体的な場面（誰が・いつ・何に困るか）を入れる。
   - AI の使い方・工夫: Google の AI をどこにどう使ったか、使ったことで何が変わるか（AI活用の有効性）。ほかにない点（独創性）。
   - 生まれた変化・広がり: 使った人に何が変わるか、ほかの人・地域・場面にどう広がるか（展開可能性）。
   - KOZAROCKS 2026 の「文創開化」（AI で何でも量産できる時代に、土地の歴史や人の物語など再現できないものを価値として「活かして創る」）に結びつく題材なら、その視点を1文だけ入れる。結びつかないのに無理に入れない。
   - requirements.md に無い数字や実績を作らない。分からないことは書かない。
7. 部門は requirements.md の「4. 部門」をそのまま書く。使った AI ツールは、requirements.md の「3. 使う Google の AI」と、アプリを作った道具（Antigravity など）から選ぶ。選べるのは Gemini / Gemini Notebook / Google AI Studio / Google Antigravity / その他 の5つ。
8. 「審査基準の確認」に、4つの基準それぞれが概要と PR のどこに入っているかを1行ずつ書く。入っていない基準があれば、足すよう促す。
9. **`challenge/entry_form.json` も書く**（/ai-challenge-kit:entry-submit がフォームへの入力に使う）。UTF-8 の JSON で、キーは次の13個。値が空のものは `""`（`ai_tools` は `[]`）にする。選んだタイトル案は `title` に入れる。

   ```json
   {
     "name": "",
     "email": "",
     "pen_name": "",
     "title": "",
     "summary": "",
     "category": "暮らしと家族",
     "youtube_url": "",
     "pr": "",
     "product_url": "",
     "story_background": "",
     "story_ai_usage": "",
     "story_impact": "",
     "ai_tools": ["Gemini", "Google Antigravity"]
   }
   ```

   - `category` は「暮らしと家族」「はたらく・まなぶ」「まちと地球の未来」のどれか1つ（「部門」の語は付けない）。
   - `ai_tools` の値は「Gemini」「Gemini Notebook」「Google AI Studio」「Google Antigravity」「その他」から選ぶ。
   - `youtube_url` は、本人が限定公開でアップしたあとに貼る。この時点で空でよい。
   - `pr` は、公式フォームに対応する入力欄がありません。動画の説明文などに使う一言（60字程度）を書く。フォームには入力されない。
   - `product_url` は /ai-challenge-kit:deploy で得た URL（無ければ空）。
10. 最後に参加者に伝える: 「**自分の言葉で、具体的な場面を1つ足してください。** 例えば『先月、母が…』のように、実際にあった場面を1〜2文で書くと、伝わり方が変わります」。「自分の言葉で書き足す一か所」の見出しに、足す位置の目安を書く。足してもらった文は、md と json の両方に反映する。
11. `challenge/progress.md` があれば、⑨ 応募文を「済」に更新する（無ければ作らず、/ai-challenge-kit:challenge を勧める）。
12. 次は `/ai-challenge-kit:entry-submit` でフォームに入力する、と勧める。提出は本人が公式ページ https://googlejp25.withgoogle.com/awards/ からも行える、締切は 2026/11/30 23:59 と伝えて終わる。

## 気をつけること

- 応募フォームの同意のチェックと送信は本人が行う。代行しない。
- 公式の項目や文字数の目安が変わっている可能性があるので、提出前に公式のフォームで確かめるよう添える。
- 氏名・メールアドレスは `challenge/` のファイルにだけ書き、Git にコミットしない。API キーやパスワードはどこにも書かない。
