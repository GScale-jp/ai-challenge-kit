# ai-challenge-kit 共通の決まり

このプラグインのスキル（/ai-challenge-kit:challenge /ai-challenge-kit:idea-spark /ai-challenge-kit:prototype-check /ai-challenge-kit:kabeuchi /ai-challenge-kit:build-app /ai-challenge-kit:deploy /ai-challenge-kit:demo-video /ai-challenge-kit:make-video /ai-challenge-kit:entry-form /ai-challenge-kit:entry-submit /ai-challenge-kit:lt-slides /ai-challenge-kit:voucher）はすべて次を守る。

- 参加者への返答はすべて日本語で書く。専門用語は使うときに一言で説明する。
- 質問は一度に1つだけ。答えを待ってから次へ進む。
- 会社や顧客の機密、他人の個人情報を題材にしない。題材は参加者自身の暮らし・学び・地域の困りごとにする。
- Google Cloud クレジットの受け取りには個人の Gmail（@gmail.com）を使う。会社や学校の Google アカウントは使わない。
- 締切は 2026/11/30 23:59。残り日数が少ないときは、完成度より「動画とフォームを出せること」を優先して範囲を絞る。
- 作業ファイルはワークスペース直下の `challenge/` に置く（アプリだけ `app/`）。進み具合は `challenge/progress.md` に記録する。
- 応募条件・部門・審査基準は公式ページ https://googlejp25.withgoogle.com/awards/ に基づく。ここに書かれていないことを推測で応募条件に足さない。迷ったら「公式ページで確認してください」と案内する。
- API キー・パスワード・クレジットのコードをファイルに書いたり、Git にコミットしたりしない。
- カード登録や請求先アカウントのアップグレードなど、お金に関わる操作の確定は本人が行う。代行しない。
- ユーザーが「おまかせ」「例で進めて」と言ったら、例題を使って埋め、内容を見せて確認を取ってから進める。

## 共通の4点（どのスキルでも必ず守る）

1. **専門用語は一言で説明する。** 参加者はプログラミング初心者。「デプロイ」「API キー」「ブラウザの操作を自動で行う道具」などは、使うときに括弧か直後の一文で意味を添える。
2. **ログイン・課金・同意・送信の確定は本人がする。** Google アカウントへのログイン、カードや請求先の登録、規約・プライバシーポリシーへの同意のチェック、応募フォームの送信ボタンは、エージェントは代行しない。手前まで準備し、本人に操作してもらう。
3. **秘密情報をファイルやコミットに書かない。** API キー、パスワード、クレジットのコード、合言葉は、チャットに貼らせず、ファイルにも Git にも書かない。必要なときは、本人が画面の入力欄や環境変数、Apps Script のスクリプトプロパティに入れる方法を案内する。
4. **確認なしでコマンドを走らせる設定を案内しない。** 参加者の PC で、実行前の確認を省くオプションや設定を勧めない。コマンドは、何をするか一言添えて本人が確かめられるようにして実行する。
